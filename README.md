# 英语词根词缀学习台

一个**单文件、零依赖、可离线使用**的英语词根词缀学习应用。把「前缀 / 词根 / 后缀」的速查、按语义分类的系统学习、间隔重复训练和进度管理整合在同一个 HTML 页面里，双击即用。

全部数据内嵌在文件中，不联网、不上传，学习进度保存在浏览器本地。

## 快速开始

1. 下载或用浏览器直接打开 `英语词根词缀学习台.html`（双击即可）。
2. 顶部切换「首页 / 学习 / 训练 / 进度」四个模式。
3. 点击例词即可记录学习次数，**同一单词点满 10 次自动标记为「已掌握」**（整行变绿）。

无需安装 Node、无需启动服务器；推荐使用 Chrome、Edge、Firefox、Safari 等现代浏览器。

## 功能一览

### 首页

- 四项核心指标：词根词缀总数、典型例词总数、已掌握例词、语义分类数。
- 掌握进度条，直观显示整体完成度。
- 按语义类别分组的卡片网格，点击任意词缀可打开明细弹窗。

### 学习

- 三类切换：**前缀（46）/ 词根（69）/ 后缀（32）**，共 147 个词条。
- 每个词条展示：形式、变体、含义、语义分类、难度等级、词源。
- 例词按**名词 / 动词 / 形容词 / 副词 / 其他**分组排列，同词性内按释义排序。
- 每个例词标注：**音标**、**汉字谐音**（规则生成的近似助记）、中文释义，并用红色加粗高亮词素位置（如 **un**happy）。
- 卡片底部附 **AI 洞察**（词根由来 / 含义与构词 / 记忆技巧三段）与 **记忆提示**。
- 支持关键词搜索（跨前缀·词根·后缀，可命中词素、变体、含义、语义组名、例词）以及语义、难度筛选。
- 有搜索词时自动跨三类全局匹配；语义分组可折叠，避免长列表刷屏。

### 训练

- 基于**简化间隔重复（步进阶梯）**：复习间隔阶梯为 `0 / 1 / 3 / 7 / 16 / 30` 天。
- 卡片式自测：先看词素，点击「翻看」后显示释义、例词与记忆提示。
- 三档自评：**忘了 / 模糊 / 会了**，分别重置、保持、推进复习阶梯。
- 只抽取当天到期的词条；全部完成可「再来一轮（复习全部）」。

### 进度

- 点击维度与训练维度分开统计：已掌握 / 学习中 / 未学。
- **易忘词条**榜：训练评级为「忘了」，或存在多次点击仍未掌握的例词，按比例排序取前 30。
- 数据管理：导出备份 JSON、导入恢复、清空全部进度。

## 数据规模

| 分类 | 词条数 | 例词数 |
| --- | ---: | ---: |
| 前缀 | 46 | 2,124 |
| 词根 | 69 | 1,138 |
| 后缀 | 32 | 2,707 |
| **合计** | **147** | **5,969（去重后 3,043 个唯一单词）** |

- 语义分组 15 个：前缀 5 类（否定·相反 / 时间·顺序 / 空间·方位 / 数量·程度 / 态度·评价·关系），词根 6 类（人体·生物 / 自然·宇宙 / 心理·认知 / 动作·行为 / 数量·状态·性质 / 时间·空间），后缀 4 类（名词 / 动词 / 形容词 / 副词后缀）。
- 难度等级：初中基础 16 条、四级 111 条、六级/考研 20 条。
- 例词取自 CET-4 词表，已去重并过滤「read 被 re- 误标」这类假阳性。

> 注：少数低频词根（如 `meteor-`、`chron-`、`sept-`）在四级词表内无匹配例词，卡片的例词数显示为 0，不影响其他功能。

## 项目结构

```
词根词缀/
├── 英语词根词缀学习台.html          # 应用本体（单文件，约 906 KB，含全部数据）
├── README.md                        # 本文件
├── 英语词根词缀学习台-优化说明.md    # 例词归类 & AI 洞察增强说明
└── 英语词根词缀分类速查-交付说明.md  # 早期「分类速查」版本的交付记录
```

整个应用由 `<style>` + HTML 骨架 + `<script>` 组成，JS 分为：数据层（`APPDATA`）、状态持久化、首页渲染、学习列表、明细弹窗、训练（SRS）、进度统计、导入导出。

## 数据与隐私

- 进度保存在 `localStorage`，键名为 `affix_learn_v1`，结构为：

  ```json
  {
    "version": 1,
    "clicks": { "单词": 点击次数 },
    "srs":    { "词条 id": { "step": 1, "due": "2026-11-02", "last": "2026-10-26" } }
  }
  ```

- 换浏览器、换设备或清理浏览器数据都会丢失进度，请先用「导出备份」保存 JSON，再在目标设备「导入恢复」（导入为**合并**语义，不会覆盖已有记录）。
- 全部数据与逻辑都在本地，不上传任何内容。

## 自定义

- **增删词条**：编辑 HTML 中的 `const APPDATA = {...}` 数据块，按现有字段结构（`form / v / m / sem / lv / src / tip / insight / words / summary`）追加即可，无需改渲染逻辑。
- **调整掌握阈值**：修改 `const MASTERED = 10;`。
- **调整复习间隔**：修改 `const STEPS = [0,1,3,7,16,30];`。
- **换配色**：CSS 变量集中在 `:root` 的 `--blue / --red / --green` 等。

## 已知说明

- 汉字谐音是按读音规则自动生成的**近似助记**，仅供跟读参考，不等同于标准音标。
- 共有 46 处例词缺少音标字段，显示时自动省略音标，不影响释义与其他信息。
- `英语词根词缀分类速查-交付说明.md` 中提到的独立文件 `英语词根词缀分类速查.html` 未包含在本仓库，其能力已整合进当前的学习台。
